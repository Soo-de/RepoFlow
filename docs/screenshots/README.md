# RepoFlow Screenshots

Place your screenshots in this directory with the following filenames:

1. `01_main_screen.png` — Main dashboard showing repo URL input, platform selection, and model configuration.
2. `02_detail_screen_logs.png` — Execution detail view showing real-time SSE analysis logs and self-healing trace.
3. `03_detail_screen_pipeline.png` — Pipeline view showing generated YAML CI/CD workflow (GitHub Actions / Azure Pipelines).
4. `04_detail_screen_dockerfile_repo.png` — Dockerfile detail view showing repository-detected Dockerfile.
5. `05_detail_screen_dockerfile_llm.png` — Dockerfile detail view showing LLM-generated production Dockerfile.
